What may Haiku see when it decides to write a note? The 2026-08-12 recommendation was directory faces only, but that was phrased against org node paths. This project has no node tree, so the equivalent surface needs re-grounding before the question is decidable. Do not implement the Haiku writer until this is locked.

Related open question: entry-router is already a durable Haiku read-router over the same lake (02_CONTENT/entry-router/). Mailman's Haiku writer is either its first real consumer or a second competing pipeline - reconcile before building. Note also entry-router/NOTE_node-addresses.md (2026-08-08): a prototype already emits id/address/axis/title/description/state/assigned_to/path per entry, which is a directory face. That note states the scheme is unratified and may be re-cut by S3/A3.
