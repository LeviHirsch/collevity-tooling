# Simplifier critique — Revision 2

## 1. Cross-part dependencies — over-documentation

D1/D2/D3 cite DEC numbers, function names (`read_day`, `sync_sources`, `append_entry`), and file names (`lake.py`) for work this spec explicitly does not implement ("dependencies, not hook ACs"). That's part-1's implementation detail bleeding into a spec that should only need to name *what it's blocked on*, not *how part-1 will fix it*. Cut all three to one pointer: "Blocked on part-1 backlog: (a) sub-minute read_day ordering, (b) settle-time chronological compaction, (c) concurrent-append safety — see part-1 deferred list for DEC references." If a reader needs the mechanism, they go to part-1's spec. Carrying it here means two specs describe the same fix and drift out of sync the first time part-1's approach changes.

**Restatement count for the same caveat** ("ordering of same-minute entries depends on D1"): Cross-part deps (D1), Constraints ("Chronological order is a read/settle concern"), Success criteria (bullet 3 parenthetical), AC5.1 parenthetical, and Implementation phases (Phase 2 line). Five places, one fact. Say it once — in Cross-part dependencies — and have the other four cross-reference it instead of restating it.

## 2. AC4.3 (error sidecar) — gold-plating

A fail-open hook is *designed* to swallow failures silently. AC4.3 adds a second file, a second write path, and its own "swallow the failure of the swallow" logic — machinery to observe a failure mode (iCloud write contention, missing env var) that's rare by construction and already has a cheaper breadcrumb: a missing lake entry is itself detectable by comparing prompt-submission count to lake line count, or simply noticing `read_day` under-reports. The sidecar doesn't earn double the file-write risk surface for a v1 hook whose whole point is "pure plumbing, no LLM, no failure handling beyond exit 0." Recommend cutting AC4.3 entirely for v1 and deferring "capture-loss observability" to whenever real data shows losses are non-negligible. If a breadcrumb is wanted now, a single `logger` call to a shared debug log (already-existing infra) beats a dedicated sidecar file + path + install step.

## 3. Other redundancy

- Constraints and Success criteria both spell out the full `created_at` format example/precision language — collapse to one canonical statement, ACs cross-reference it.
- Out of scope's D1–D3 bullet again re-explains "hook does not re-sort the lake" — already stated in Constraints. Cut the repeat, keep only the scope boundary line.
