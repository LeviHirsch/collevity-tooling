## Notes — design decisions made during build (surface for Levi's judgment)
1. **Closed top level (AC1.8).** Chose to reject unknown top-level keys, not just the named-excluded ones, pushing remainder into `source_data` (DEC-012). Stricter than the AC's literal "document excludes"; defensible as it operationalizes the exclusion. Veto → relax to allow-unknown.
2. **`time` = 'HH:MM'.** Parity target script absent; assumed shape (see AC3.1 note).
3. **Pool path resolution.** arg → `COLLEVITY_ENTRY_POOL` env → package-default `data/entries.jsonl`. Spec was silent on the physical pool location; this is a dev-default + override pattern, `data/` gitignored.
4. **Module layout.** `entry_store/` package (ids/schema/store/sync) with the seam exported from `__init__`. Conventional; not spec-dictated.
