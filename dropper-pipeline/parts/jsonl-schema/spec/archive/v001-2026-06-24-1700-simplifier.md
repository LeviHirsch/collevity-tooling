# Simplifier Review — JSONL Schema Spec (v001, Revision 2)

## Pass 1: Catalog

Components: Goal, 6 Constraints, 4 Success Criteria, 11 Out-of-Scope items, 19 AC leaves (AC1×8, AC2×3, AC3×2, AC4×6), 2 Phases, 4 Open Questions.

## Pass 2: Challenge

**AC1.6** specifies the `claude-hook` context shape (`{kind, session_id, seq, parent_id?}`) — then declares it "reserved in v1, not validated." The hook channel doesn't exist yet (part 3). Nothing breaks if this is deleted and the shape is defined in part 3's spec. Reserving shape for a hypothetical channel is premature.

**AC1.7 (`meta_notes` convention)** documents an append-only timestamp convention but explicitly calls it "a convention, not a validated constraint." Un-testable items don't belong in the AC tree. Move to implementation notes.

**AC1.8** enumerates 8 excluded fields. Negative-space documentation rots. If the schema doesn't include those fields, AC1.8 is noise — and a future maintenance hazard when the exclusion list changes.

**AC4.4 body** names EDT (`-04:00`) and MDT (`-06:00`) offsets. That's runbook detail, not an AC. Open Questions already defers *how* MDT rows are identified. AC4.4 should say "every legacy row carries a correct explicit offset after one-time backfill" and stop.

**AC4.6** prescribes "piggybacking `read_day` / consumers" as the ingest cadence. Implementation choice, not requirement. Requirement: no daemon/cron; idempotent per session.

**AC4.2** specifies "sub-second tiebreaker by row index." Mechanism, not requirement. Requirement: stable unique key per Excel row.

## Pass 3: Minimum viable cut list

1. **Delete AC1.6** — define the context shape in part 3 when the hook exists.
2. **Delete AC1.8** — schema omissions need no AC.
3. **Trim AC1.7** — keep field presence and type; drop the `meta_notes` convention prose.
4. **Trim AC4.4** — strip EDT/MDT specifics; keep "correct offset via one-time backfill."
5. **Trim AC4.6** — restate as requirement; remove the read-time piggyback mechanism.
6. **Trim AC4.2** — remove "sub-second tiebreaker by row index."

Remaining ACs (AC1.1–1.5, AC2.1–2.3, AC3.1–3.2, AC4.1, AC4.3, AC4.5) are load-bearing.

## Pass 4: Over-specification

The Constraints section repeats the required-floor field list already in AC1.1–AC1.4 — two places to keep in sync. Pick one; the other is a maintenance hazard.

The Out-of-Scope entry "Whether to replace Excel at all" is architectural framing, not a scope boundary. Cut it.
